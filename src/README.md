
# Research Implementation

This folder contains the Python scripts used for the final YOLO26n diabetic foot ulcer localization research.

The implementation includes dataset screening, model training, dataset verification, region-size evaluation, selective high-resolution refinement, and inference-performance analysis.

The scripts were developed using the original local project directory. Some dataset-dependent scripts require their file paths to be configured before execution on another computer.

The original datasets are not included in this repository.
