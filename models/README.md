
# Final YOLO26n Model

This folder contains the final trained YOLO26n checkpoint
for diabetic foot ulcer localization.

- Model: YOLO26n (nano)
- Training epochs: 50
- Input resolution: 512 x 512
- Batch size: 4
- Dataset: Final screened DFU research dataset (7,077 images)
- Checkpoint: best.pt

The model is intended for research and educational use.
It has not been clinically validated and must not be used
as a standalone medical diagnostic tool.
